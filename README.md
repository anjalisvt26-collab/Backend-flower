Flower Backend Login Page

A flower-themed login page built using Node.js, Express.js, and EJS. This project demonstrates backend routing, form handling, and server-side rendering with a beautiful flower-inspired user interface.
✨ Features

🌹 Attractive flower-themed login page

🔐 Login form with email and password fields

⚙️ Backend server using Node.js and Express.js

🖥️ Dynamic page rendering using EJS

📩 Form submission handling

📁 Organized project structure
